Capabilities Cheatsheet

AirSave performs direct right-click uploads. Here is everything you can save:

🖼️

Images

Right-click any web image and select "Save Image to Google Drive".

🎵

Audio & Video

Right-click any audio/video element and select "Save Audio/Video to Google Drive".

🔗

Links & PDFs

Right-click any download link (Spreadsheets, ZIPs, PDFs, etc.) and select "Save Linked File to Google Drive".

📝

Snippet Clipper

Highlight text on a webpage, right-click, and select "Save Snippet to Google Drive".

📸

Screenshots

Right-click any blank area of a page and select "Save Screenshot to Google Drive".

💡 All files are saved directly inside the target "Saved from Browser" folder in your Google Drive.
